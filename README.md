# 🧠 Второй мозг — Telegram Mini App

Личная база знаний с ИИ на Together AI: быстрый захват мыслей, автотегирование,
чат с собственными заметками (RAG), дневник с рефлексией, задачи, которые ИИ
умеет находить прямо в тексте заметок, и визуальная «карта мыслей» — заметки
как нейроны, связанные по темам и датам.

Это **фронтенд-прототип для теста**: Together API дергается прямо из браузера,
ключ хранится в `localStorage` устройства пользователя. Для продакшена читайте
раздел «Как перенести на бэкенд» ниже — это важно, ключ в клиентском коде видно
любому, кто откроет DevTools.

---

## Что нового в этой версии

- **Вкладка «Записи» переделана**: вместо «Все / Заметки / Дневник / Задачи»
  теперь три раздела — **Заметки, Дневник, Задачи**. Поиск больше не висит
  постоянной строкой сверху — это маленькая иконка-лупа рядом с картой мыслей,
  открывающая поле поиска по нажатию.
- **Дневник переделан с нуля**: полоска последних 7 дней с индикатором
  настроения по каждому дню (клик по дню — переход к записи в истории),
  бейдж серии дней рядом с заголовком, компактная карточка «сегодня»
  (настроение + текст + рефлексия ИИ), и история в виде карточек с датой
  слева — как в календаре.
- **Задачи**: фильтр статуса теперь только «Открытые» / «Выполненные» —
  лишний пункт «Все» убран.
- **Карта мыслей** — связи стали заметно чище: у каждой заметки теперь **не
  больше 3 связей** (отбираются самые сильные — по числу общих тегов), сама
  карта выше и просторнее, линии окрашены акцентным цветом с переменной
  толщиной/прозрачностью по силе связи.
- **Премиальные SVG-иконки** вместо части эмодзи в интерфейсе — поиск,
  закрепление, карта мыслей, серия дней, ✨-действия ИИ, экспорт/импорт,
  обучение — единый минималистичный стиль обводки вместо смеси эмодзи.
- **Один JS-файл** (`app.js`) вместо четырёх модулей — см. «Структура» выше.

## Что внутри

| Экран | Что умеет |
|---|---|
| **Главная** | быстрый захват мысли, свежие заметки |
| **Записи → Заметки** | закрепление, карточки-«каталог», редактирование, поиск по иконке |
| ИИ в заметке | ✨ автотег (категория + теги + заголовок) · ✅ извлечение задач из текста · 📝 сжатие в резюме · закрепление |
| **Записи → Дневник** | полоска недели с настроением, запись дня, ИИ-рефлексия дня, история по датам, ИИ-итог недели |
| **Записи → Задачи** | ручное добавление, фильтр Открытые/Выполненные, массовое извлечение задач из любой заметки |
| **Записи → Карта мыслей** | заметки как нейронная сеть — связи по общим тегам (макс. 3 на заметку), положение по датам и категориям |
| **ИИ-чат** | вопросы к своей базе заметок (RAG: под капотом ищутся релевантные заметки и передаются модели как контекст, в ответе видно источники) |
| **Профиль** | статистика, график активности, API-ключ, выбор модели, тест соединения, повтор обучалки, экспорт/импорт JSON, полная очистка данных |

Никакого бандлера — чистые HTML/CSS/JS-модули, поэтому можно просто выложить
папку на любой статический хостинг.

## Структура

```
second-brain/
├── index.html   разметка всех экранов + модалок (заметка, настройки, карта мыслей, обучалка)
├── styles.css   дизайн-система (тёмная тема, переменные, компоненты)
├── app.js       весь JS одним файлом: слой данных (localStorage), клиент Together AI
│                (RAG-чат, автотег, извлечение задач, саммари), интеграция с Telegram
│                WebApp и вся логика экранов/рендера/карты мыслей
└── README.md
```

Раньше JS был разбит на 4 модуля (`storage.js`, `together.js`, `telegram.js`, `main.js`),
теперь всё это — один файл `app.js`, обёрнутый в IIFE (без `import`/`export`), так его
проще скопировать целиком или вставить в другой проект.

## 1. Быстрый запуск локально

Модули (`type="module"`) не грузятся с `file://` — нужен локальный сервер:

```bash
cd second-brain
python3 -m http.server 8080
# или: npx serve .
```

Откройте `http://localhost:8080`. Приложение прекрасно работает и в обычном
браузере — Telegram-интеграция (`telegram.js`) в этом случае просто отключается,
всё остальное работает как есть. При первом запуске покажется мини-обучалка.

## 2. Добавьте ключ Together AI

1. Зарегистрируйтесь на [together.ai](https://www.together.ai), возьмите API-ключ в личном кабинете.
2. В приложении откройте ⚙ **Настройки → Together API ключ**, вставьте ключ —
   баннер «нет ключа» исчезнет сразу же.
3. Нажмите **Тест** — должно появиться «✓ Подключение работает».
4. При желании смените модель (поле с автодополнением, можно вписать любой
   актуальный ID модели из вашего кабинета Together — список моделей у них
   периодически меняется, поэтому в коде это просто текстовое поле, а не
   жёстко зашитый список).

## 3. Разверните как Telegram Mini App

1. Залейте папку `second-brain` на статический хостинг с HTTPS — например
   GitHub Pages, Vercel, Netlify, Cloudflare Pages.
2. В [@BotFather](https://t.me/BotFather): `/newapp` (или `/setmenubutton` /
   `/mybots → Bot Settings → Menu Button` для существующего бота) → укажите
   HTTPS-адрес вашего хостинга.
3. Откройте бота в Telegram — кнопка меню/команда откроет мини-апп, шапка и
   фон клиента Telegram будут принудительно чёрными (см. `telegram.js`).

## ⚠️ Важно про CORS

Together AI поддерживает прямые запросы из браузера (`fetch` с CORS), но
провайдеры время от времени меняют политику. Если при тесте соединения видите
ошибку сети — скорее всего это CORS-блокировка. В таком случае единственное
надёжное решение — прокси-эндпоинт на своём сервере (см. ниже), тестовый режим
«всё на фронте» для того и существует, чтобы вы это сразу увидели.

## Как перенести на бэкенд (когда будете готовы к продакшену)

Сейчас единственное место, где происходит обращение к Together API — файл
`js/together.js`, функция `rawChat()`. Чтобы спрятать ключ на сервере:

1. Поднимите лёгкий бэкенд (Node/Express, Cloudflare Workers, Vercel
   Functions — что угодно) с одним эндпоинтом, например `POST /api/chat`,
   который принимает `{ messages, model }` и сам делает запрос к
   `https://api.together.xyz/v1/chat/completions`, подставляя ключ из
   переменных окружения сервера.
2. В `rawChat()` замените `fetch(API_URL, ...)` на `fetch('/api/chat', ...)`
   и уберите заголовок `Authorization` — сервер сам его добавит.
3. Уберите поле ввода API-ключа из настроек (или оставьте — но тогда
   игнорируйте его на бэкенде).
4. Добавьте на сервере лимиты/аутентификацию пользователей Telegram (Mini
   Apps передают `initData`, которую можно и нужно проверять на сервере —
   это подтверждает, что запрос действительно пришёл из вашего бота).

Остальной код (`storage.js`, `main.js`, вёрстка) трогать не придётся — весь
интерфейс уже общается с ИИ только через функции `Together.*`.

## Карта мыслей — как это устроено

Полностью на фронтенде, без эмбеддингов и без бэкенда:

- позиция заметки по горизонтали — нормализованная дата создания (от первой
  до последней заметки в базе);
- по вертикали заметки распределены по «полосам» — одна полоса на категорию;
- связи (линии) рисуются между заметками, у которых совпадает хотя бы один
  тег — так на графе видно тематические цепочки;
- размер и лёгкая пульсация нейрона зависят от количества тегов и того,
  закреплена ли заметка.

Если захотите более «умную» карту — следующий шаг это эмбеддинги
(Together AI поддерживает Embeddings API) и честная кластеризация по
смыслу, а не только по тегам.

## Данные и приватность

- Все заметки/задачи/дневник хранятся **только в localStorage браузера
  пользователя** — между устройствами не синхронизируются. Для синхронизации
  тоже понадобится бэкенд + база данных.
- Экспорт (⚙ → Данные → Экспорт JSON) делает полный бэкап без API-ключа —
  им можно поделиться безопасно или восстановить данные на другом устройстве
  через Импорт.

## Идеи для дальнейшего развития

- Векторный поиск (embeddings API Together) вместо текущего поиска по
  пересечению слов — даст более точный RAG и более «умную» карту мыслей.
- Голосовой ввод через Web Speech API.
- Перетаскивание нейронов на карте мыслей (простая force-simulation).
- Пуш-уведомления о задачах через Telegram Bot API с сервера.
